# 📊 Excel Learning Material — SMK Class 11

Comprehensive Excel learning material for Indonesian vocational high school (SMK) Class 11 students.

## Features

- 📝 **Formula Reference** — SUM, AVERAGE, MAX, MIN, COUNT, IF
- 🔍 **VLOOKUP Tutorial** — With practical examples
- 🔀 **IF & Nested IF** — Grade calculations
- 📊 **SUMIF & COUNTIF** — Conditional sum and count
- 📈 **Charts** — Bar charts, pie charts
- 📝 **Practice Exercises** — Fill-in-the-blank worksheets

## Excel Sheets

| Sheet | Content |
|-------|---------|
| 1. Tabel Nilai Siswa | 10 students + formulas |
| 2. VLOOKUP | Student lookup examples |
| 3. IF & Nested IF | Grade calculations |
| 4. SUMIF & COUNTIF | Sales data analysis |
| 5. Chart Grafik | Monthly sales charts |
| 6. Latihan | Practice exercises |

## Quick Start

```bash
cd scripts
python3 gen_excel_smk.py
```

Output: `Excel_Kelas11_SMK.xlsx`

## Customization

Edit `scripts/gen_excel_smk.py` to:
- Add more students
- Change grade thresholds
- Modify chart data

## Requirements

- Python 3.8+
- openpyxl (`pip install openpyxl`)
